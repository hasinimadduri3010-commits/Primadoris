HOW IT WORKS

Five canary inputs are stored in models/baseline.json at training time. On every status poll, the live EdgeExtractor model runs these inputs and its outputs are compared to the stored embeddings.

Drift is computed as ‖actual − expected‖ / ‖expected‖ per probe. If max_drift > 0.10 (threshold configurable in config.py), the system enters QUARANTINE.
